# Changelog

История развития проекта Giga Watt.

---

## [0.1.1-foundation] — Foundation Hardening + Fixtures

Технический проход после Iteration 001, без новой предметной области.

Исправлено:

- дефект триггера иерархии `organization_units`: смена родителя/типа
  существующего узла могла оставить дочерние единицы под недопустимым
  родителем и даже образовать цикл в цепочке `parent_id`; добавлена
  защита на уровне БД (см. миграцию `000006`) и regression-тесты.

Добавлено:

- автоматические тесты (`go test`) для ключевых инвариантов Foundation:
  организационная иерархия, кадровые назначения, контакты сотрудников,
  штатные единицы, объекты эксплуатации;
- воспроизводимые fixtures: Excel-источник исходных данных
  (`fixtures/initial-data.xlsx`) и загрузчик (`backend/cmd/fixtures`);
- ADR-0005 (схема версионирования).

## [0.1.0-foundation] — Iteration 001 Foundation

Первый предметный слой цифрового двойника предприятия.

Добавлено:

- организационная структура (Учреждение → Филиал → ЖКС → ПУ) с жёсткой
  иерархией;
- сотрудники: ФИО с автогенерацией сокращённого имени, дата рождения,
  пол, телефоны/e-mail (1:N, с основным контактом);
- кадровые назначения (сотрудник ↔ организационная единица ↔ должность);
- справочник должностей;
- штатные единицы (организационная единица + должность + количество);
- справочники типов и назначений объектов эксплуатации;
- объекты эксплуатации, принадлежащие только ПУ;
- backend API (Go, net/http, pgx, SQL-first) и frontend (Nuxt) для всех
  перечисленных сущностей.
