# ADR-0001 — SQL-first approach

## Status

Accepted

## Date

2026-08-07

---

## Context

Giga Watt создаётся как платформа цифрового двойника предприятия.

На раннем этапе необходимо сохранить прозрачность модели данных и тесную связь с предметной областью.

---

## Decision

Использовать SQL-first подход.

Структура базы данных проектируется явно через SQL-миграции.

Backend использует PostgreSQL и pgx без использования ORM как основного слоя доступа к данным.

---

## Reasons

- Полный контроль над моделью данных.
- Прозрачность структуры предприятия.
- Отсутствие скрытого поведения ORM.
- Простота оптимизации запросов.
- Хорошая подготовка к развитию модулей.

---

## Consequences

Плюсы:

- явная модель данных;
- контроль SQL;
- предсказуемость работы.

Минусы:

- больше ручной работы;
- ответственность за проектирование запросов лежит на разработчике.

---

## Status

Accepted.
