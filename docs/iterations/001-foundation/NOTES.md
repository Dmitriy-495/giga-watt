## Domain Notes

### Organizational Structure

Структура предприятия фиксирована:

```text
Учреждение → Филиал → ЖКС → ПУ

ПУ является одновременно организационной, территориальной и эксплуатационной единицей.

Operational Objects

Объект эксплуатации является родовой сущностью.

Понятия "здание", "сооружение", "сеть" и т.п. не создаются отдельными сущностями на данном этапе.

Конкретная природа объекта может отражаться в его наименовании.

Object Type

Тип объекта — редактируемый справочник.

Начальные значения:

Коммунальный объект;
Объект ЖФ;
Объект КЖФ.
Object Purpose

Назначение объекта — редактируемый справочник.

Каждое назначение связано с типом объекта.

Это используется для ограничения выбора назначения при создании и редактировании объекта.

Experimental Production Unit

Экспериментальный ПУ не содержит:

коммунальных объектов;
объектов ЖФ.

Допускается наличие объектов КЖФ.

Это ограничение экспериментальных данных, а не предметной модели.

Future Development

Предполагается дальнейшее развитие:

штатной модели;
кадровой истории;
совместительства;
совмещения;
временных переводов;
специализированных характеристик объектов;
эксплуатационных процессов.

Эти функции сознательно не реализуются целиком в Iteration 001.
