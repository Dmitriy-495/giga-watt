# Giga Watt System Architecture

## Overview

Giga Watt — платформа цифрового двойника предприятия коммунальной инфраструктуры.

Система предназначена для создания цифровой модели предприятия:

- структуры;
- объектов;
- ресурсов;
- сотрудников;
- документов;
- процессов;
- событий.

# Platform

Platform является фундаментом приложения.

Она содержит общие технические механизмы:

- конфигурацию;
- логирование;
- подключение к базе данных;
- HTTP слой;
- общие инфраструктурные компоненты.

Platform не содержит бизнес-логики предприятия.

---

# Modules

Модули являются элементами цифрового двойника.

Каждый модуль:

- имеет собственную предметную область;
- отвечает за свои данные и процессы;
- проектируется как потенциальный самостоятельный сервис.

На старте система является модульным монолитом.

---

# Modular Monolith

Первый этап разработки использует один backend процесс.

Причины:

- простота эксплуатации;
- скорость разработки;
- отсутствие преждевременной распределённости.

При необходимости отдельные модули могут быть выделены в самостоятельные сервисы.

---

# Data Model

PostgreSQL является основной системой хранения данных.

Подход:

- SQL-first;
- явные миграции;
- прозрачная модель данных.

---

# Events

Внутренние события используются для связи процессов внутри системы.

Событийная модель должна отражать реальные процессы предприятия.

---

# Main Principle

Архитектура существует не ради технологий.

Архитектура должна помогать точнее моделировать предприятие.
