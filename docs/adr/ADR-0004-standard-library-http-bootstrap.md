# ADR-0004 — HTTP Bootstrap на стандартной библиотеке Go

**Статус:** Accepted  
**Дата:** 2026-08-08

## Контекст

Giga Watt строится как модульный монолит и платформа цифрового двойника.

На этапе Bootstrap необходимо минимальное HTTP API для проверки работоспособности backend.

Изначально рассматривалось использование Gin как HTTP-фреймворка.

При этом текущая версия Go в окружении проекта — Go 1.22.3, а использование актуальной версии Gin привело к дополнительным требованиям к версии Go и значительному набору транзитивных зависимостей.

В соответствии с принципом минимизации зависимостей принято не использовать внешний HTTP-фреймворк там, где задача полностью решается стандартной библиотекой.

## Решение

Для Bootstrap backend используется стандартный пакет:

```go
net/http

Первый HTTP endpoint реализуется без Gin и других HTTP-фреймворков.

Минимальный сервер должен обеспечивать:

запуск HTTP-сервера;
обработку API-запросов;
корректные HTTP status codes;
JSON-ответы;
graceful shutdown;
базовое логирование.
Последствия
Положительные
отсутствуют дополнительные зависимости для HTTP-сервера;
минимальный размер dependency graph;
меньше проблем совместимости версий Go;
используется стандартный и стабильный API Go;
архитектура остаётся простой на раннем этапе;
переход на внешний HTTP-фреймворк при необходимости не запрещён архитектурой.
Ограничения

Стандартная библиотека не предоставляет готовые возможности, которые могут потребоваться полноценному API-приложению:

middleware ecosystem;
удобный routing уровня специализированных фреймворков;
binding/validation;
дополнительные механизмы обработки API.

Эти возможности будут добавляться только при возникновении реальной потребности.

Правило проекта

В Giga Watt внешняя зависимость не добавляется только ради удобства, если соответствующая задача качественно решается стандартной библиотекой Go.

Это правило не является абсолютным запретом на зависимости.

Если специализированная библиотека существенно упрощает сложную или предметно значимую задачу, её использование может быть принято отдельным архитектурным решением.

Текущее состояние

Backend не имеет внешних Go-зависимостей.

go.mod содержит только:

module github.com/Dmitriy-495/giga-watt/backend
