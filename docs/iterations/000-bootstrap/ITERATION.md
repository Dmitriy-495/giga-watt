# Iteration 000 — Bootstrap

## Mission

Создать фундамент платформы Giga Watt.

Bootstrap не реализует предметную область предприятия.

Его задача — подготовить основу, на которой будут разрабатываться все последующие модули цифрового двойника.

---

## Objectives

В результате итерации должны быть готовы:

- репозиторий проекта;
- структура каталогов;
- документация;
- Backend Platform;
- Frontend Platform;
- PostgreSQL;
- миграции;
- первый HTTP endpoint;
- первый экран платформы.

---

## Restrictions

Запрещается реализовывать:

- Foundation Module
- Structure
- People
- Assets
- Geography
- Documents
- Emergency

Bootstrap создаёт только платформу.

---

## Completion Criteria

Итерация считается завершённой, если:

- Backend запускается;
- Frontend запускается;
- PostgreSQL подключается;
- миграции работают;
- GET /api/ping отвечает;
- главная страница платформы открывается;
- опубликован CHECKPOINT.
