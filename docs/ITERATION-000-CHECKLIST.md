## Критерии завершения

Iteration 000 считается завершённой, когда:

1. backend запускается;
2. `GET /api/ping` возвращает `HTTP 200 OK`;
3. PostgreSQL доступен из backend;
4. frontend запускается;
5. frontend способен обратиться к backend;
6. документация соответствует фактическому состоянию проекта;
7. изменения зафиксированы в Git;
8. изменения опубликованы в GitHub;
9. опубликован CHECKPOINT-документ передачи контекста.
